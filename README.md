# Stripe

The project focuses on handling secure payments with a clean and minimal setup.

🚀 Features

Angular 19 setup

Stripe payment integration

Reactive forms

Secure payment handling

Clean and lightweight structure

🛠️ Tech Stack

Angular 19

Stripe SDK

RxJS

TypeScript

Zone.js

Stripe Flow

User enters payment details

Stripe securely processes card data

Payment intent is confirmed

Success or failure response is handled

🔐 Security Notes

Never expose Stripe Secret Key in frontend

Always process payments using backend APIs

Use HTTPS in production
